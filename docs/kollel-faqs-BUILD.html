Build a new /kollel/faqs/ page for Morasha Kollel FAQs. Uses the Kollel terracotta color palette. The page has 8 FAQ items using native <details>/<summary> HTML accordion elements (no JavaScript needed), plus a contact CTA block at the bottom.

3. Eight FAQ accordion items

Section 1: Hero
Identical structure to the Kollel Schedule hero. Deep brown background with terracotta radial gradients. Eyebrow reads "Morasha Kollel", title reads "FAQs & Camp Policies". Same CSS as the schedule page hero.
Section 2: FAQ Accordion
Uses native HTML <details> / <summary> elements. No JS required. The first item should have the open attribute by default. Each item has a numbered index (01, 02, etc.), the question text, and a chevron icon that rotates 180 degrees when open.
HTML pattern per FAQ item:

    <span class="faq-q-num">01</span>
    <span class="faq-q-text">Where is Morasha Kollel located?</span>
    <span class="faq-q-icon">
      <!-- chevron SVG -->
    </span>
  </summary>
  <div class="faq-a">
    <p>Answer text...</p>
  </div>
</details>

Note for Izzy: Question 06 about seforim has the most complex answer, including a bulleted list with italic Hebrew terms. Make sure the WYSIWYG field supports lists and inline formatting. The full text is in the mockup file.
