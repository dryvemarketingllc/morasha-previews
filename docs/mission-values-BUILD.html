New Page
Page Overview
Build a new /mission-values/ page (or /about/mission-values/). This is a brand-new page that showcases the camp's core mission statement and the 7 MORASHA values, each with a Hebrew tagline and unique accent color.
Sections on the page:
1. Hero with inspirational quote
2. Core Mission statement (two-column layout)
3. Values intro / MORASHA letter banner
4. Seven full-bleed value rows (alternating image/content sides, each with a unique accent color)
Mockup file: morasha-mission-values.html
WordPress Implementation
Page Template: page-mission-values.php
Template Name: Mission & Values
Stylesheet: mission-values.css — enqueue conditionally via is_page_template('page-mission-values.php')
ACF Field Group: "Mission & Values"

Section 4: The 7 Value Rows
Seven full-bleed, two-column rows. Each row is a 50/50 grid with image on one side and content on the other. Even-numbered rows flip the order (image on right) using direction: rtl on the parent, then resetting direction: ltr on children.
Each value has a unique --accent CSS custom property set inline. This accent color controls the giant letter, the Hebrew tagline, and the image overlay.
HTML pattern for each value row:
<div class="value" data-i="1" style="--accent:#46764B">
  <div class="value-image" style="background-image:url('...')"></div>
  <div class="value-content">
    <div class="value-letter">M</div>
    <div class="value-title">
      <h3>Mutual Respect</h3>
      <div class="value-hebrew">...Hebrew...</div>
    </div>
    <p>Description...</p>
  </div>
</div>
Key CSS:
.value {
  display: grid;
  grid-template-columns: 1fr 1fr;
  min-height: 640px;
  --accent: var(--green);
}
/* Flip even rows */
.value[data-i="2"], .value[data-i="4"], .value[data-i="6"] {
  direction: rtl;
}
.value[data-i="2"] > *, .value[data-i="4"] > *, .value[data-i="6"] > * {
  direction: ltr;
}
.value-image {
  background-size: cover;
  background-position: center;
  min-height: 480px;
}
.value-image::after {
  content: "";
  position: absolute;
  inset: 0;
  background: var(--accent);
  mix-blend-mode: multiply;
  opacity: 0.35;
  transition: opacity .5s ease;
}
.value:hover .value-image::after { opacity: 0.15; }
.value-content {
  padding: 96px 80px;
  display: flex;
  flex-direction: column;
  justify-content: center;
}
.value-letter {
  font-family: var(--serif);
  font-size: clamp(120px, 14vw, 220px);
  line-height: 0.85;
  color: var(--accent);
  letter-spacing: -0.04em;
}
.value-hebrew {
  font-family: 'Frank Ruhl Libre', Georgia, serif;
  font-size: clamp(22px, 2vw, 30px);
  color: var(--accent);
  direction: rtl;
}
.value-content p {
  font-size: 18px;
  line-height: 1.65;
  max-width: 48ch;
}

/* Responsive */
@media (max-width: 1024px) {
  .value { grid-template-columns: 1fr; min-height: 0; }
  .value[data-i="2"], .value[data-i="4"], .value[data-i="6"] { direction: ltr; }
  .value-content { padding: 64px 48px; }
}
Hebrew font: The mockup loads Frank Ruhl Libre from Google Fonts for the Hebrew taglines. Add this to the head: <link href="https://fonts.googleapis.com/css2?family=Frank+Ruhl+Libre:wght@500;700&display=swap" rel="stylesheet">
Image overlay positioning: The .value-image needs position: relative for the ::after overlay to work. This is critical.
QA Checklist

  • MORASHA letter banner is centered and each letter shows its keyword below
