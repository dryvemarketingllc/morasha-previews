Alumni & Events Changes

Developer handoff for the Alumni & Events / Reunions page redesign.

Staging URL morashastg1.../reunions-events/
Mockup Reference morasha-alumni-events.html
Last Updated April 24, 2026
Summary of changes: The current Reunions & Events page is rebuilt as a dedicated "Alumni & Events" page. The redesign introduces: (1) a dark-green hero with radial gradient accents, (2) an Upcoming Events section with large two-column cards, (3) a Past Events section with a three-column grid, (4) an Archives section on lightest-green background, and (5) a single-tier nav (this is not a camp-specific page). The URL should change from /current-campers/reunions-events/ to something like /alumni-events/.

2. Upcoming Events: Two-Column Card Grid

WordPress implementation: These should be pulled from a custom post type (e.g., morasha_event) or from an events plugin. Filter by upcoming (date >= today). If using ACF, fields needed: event_date (date picker), event_title, event_description, event_image. The date picker value can be split into month/day/year for the stacked display.

3. Past Events: Three-Column Grid
Past events are smaller cards in a 3-column grid (2-column on tablet, 1-column on mobile). Each has a 4:3 image, a date line with month/day/year in condensed uppercase, title, and short description.
