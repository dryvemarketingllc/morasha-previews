4. Global Font Swap (applies here)
Kefa (Apple system) with Nunito Sans fallback replaces Roboto/Montserrat/Nohemi for all text 14px and above. This is a site-wide change documented in dev-notes.html but visually most impactful on the homepage headings, camp cards, and footer. 
:root {
  --font-primary: Kefa, 'Nunito Sans', sans-serif;
}
/* Apply to all body text, nav, buttons, etc. at 14px+ */
/* Keep Roboto for sub-menus, form labels, small/figcaption */
Scope: Global. See dev-notes.html Change #1 for full implementation steps.

  • Hero background photo is visibly desaturated (not full color)
  • Dark gradient overlay is present (text must be readable over any photo)
  • "Since 1964" eyebrow displays in Roboto Condensed, light-green, uppercase
  • "Built on Values." is white; "Runs on Fun." is light-green italic on its own line
  • Both CTA buttons render: white solid + white outline
  • Scroll indicator animates at bottom center of hero
  • Hero is responsive: padding collapses to 24px on mobile, text stays readable
  • Nav dropdown items show colored left borders on hover (green, navy, terracotta, blue)
  • Values slider cards have 12px rounded corners on images
  • Values letter boxes show as rounded squares (10px), not circles
  • Kefa font renders on macOS/iOS; Nunito Sans renders on Windows/Android
  • No font-size regression: text under 14px should still use Roboto
  • Footer, camp cards, legacy quote section all pick up the Kefa/Nunito font
