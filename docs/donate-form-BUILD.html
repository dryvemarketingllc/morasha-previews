New Page
Overview
A new standalone donation form page that serves as the action destination from the Give Back page. The page has a compact hero, a multi-step form card, and a sticky sidebar with donation summary and informational notes.
Preview: morasha-donate-form.html
URL: /donate/
WordPress template: Create a new page template page-donate.php
Layout
Page Layout
Two-column grid layout below a compact dark green hero. Form on the left (main column), sticky sidebar on the right.

  max-width: 1100px;
  display: grid;

}

Form
Multi-Step Form Card
The form is a single card with five numbered sections separated by hairline borders. Each section has a green numbered circle and a title. 
/* Step 1: Choose a Camp */
— 2×2 grid of selectable camp cards + full-width General Fund option
— Cards: Camp Morasha, Kehillas Yaakov, Morasha Travel, Morasha Kollel, General Morasha Fund
— Selected state: camp accent color border + checkmark badge
— Camp accent colors: green / indigo / blue / sienna / darkest-green

/* Step 2: Select an Opportunity */
— Dropdown populated from ACF opportunity data, grouped by Legacy / Meaningful
— Dropdown options should change based on camp selected in Step 1
— "Other / Custom Amount" option shows a quick-select grid + custom input
— Quick-select amounts: $1K, $5K, $10K, $18K, $36K, Other

/* Step 3: Dedication Details */
— Toggle: In Honor Of | In Memory Of | In Celebration Of | No Dedication
— When "No Dedication" selected, hide honoree name + message fields
— Fields: Honoree name(s), Dedication message (textarea, optional)

/* Step 4: Your Information */
— First name + Last name (side by side)
— Email
— Phone (optional)
— "How your name should appear on the Donor Wall" with hint: "Leave blank to remain anonymous"

/* Step 5: Payment */
— Toggle: Pay in Full | Multi-Year Pledge
— Pledge shows: Number of years (2-5) + Payment frequency (Annual/Semi/Quarterly/Monthly)
— Card fields: integrate with payment processor (Stripe, PayPal, etc.)
— Submit button: "Complete Donation"
Sidebar
Sticky Sidebar
Right sidebar sticks on scroll. Contains three elements: 
/* 1. Donation Summary Card */
— Updates dynamically as form is filled
— Shows: Program, Opportunity name, Total amount
— Total has bold serif font with top border

/* 2. Good to Know Card */
— Cream background, checklist with green checkmarks
— Items: tax-deductible, multi-year pledges, tax receipt, donor wall

/* 3. Contact Line */
— Centered text: "Questions about giving?"
— Email + phone links
Integration
URL Parameters & Deep Linking
The Give Back page should link to the donation form with URL parameters to pre-select the camp and optionally an opportunity. This allows "Donate Now" buttons in each camp section to pass context. 
/* URL parameter format */
/donate/?camp=morasha
/donate/?camp=mky
/donate/?camp=travel
/donate/?camp=kollel
/donate/?camp=general

/* Optional: pre-select opportunity */
/donate/?camp=morasha&opp=campus-naming

/* On page load, read params and:
   1. Select the matching camp card
   2. Filter the opportunity dropdown to that camp
   3. If opp param present, select that opportunity */
WordPress
ACF Data Structure
The opportunity dropdown should pull from the same ACF Repeater fields used on the Give Back page. Each camp has its own set of opportunities. 
/* Existing ACF structure from Give Back page */
Camp → Opportunity Blocks (Repeater)
  → Block Heading (e.g. "Legacy Dedication Opportunities")
  → Opportunity Items (Repeater)
    → Name (text)
    → Price (text)
    → Is Hidden (boolean, for "See More" toggle)

/* The donation form reads the same data
   and populates the <select> dropdown grouped
   by block heading (Legacy / Meaningful) */
