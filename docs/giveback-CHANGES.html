JavaScript (auto-rotation + dot click):
// Place inside a <script> tag after the donor block HTML
(function() {
  var wrap  = document.getElementById('fadeWrap');
  if (!wrap) return;
  var grids = wrap.querySelectorAll('.fade-grid');
  var dots  = document.querySelectorAll('#fadeDots span');
  var current = 0;

  function show(idx) {
    grids.forEach(function(g) { g.classList.remove('active'); });
    dots.forEach(function(d)  { d.classList.remove('active'); });
    grids[idx].classList.add('active');
    dots[idx].classList.add('active');
    current = idx;
  }

  // Click handler for dot navigation
  dots.forEach(function(d) {
    d.addEventListener('click', function() {
      show(+d.dataset.page);
    });
  });

  // Auto-advance every 4 seconds
  setInterval(function() {
    show((current + 1) % grids.length);
  }, 4000);
})();

3. Pull Real Donor Names from Donor Wall ACF Data
The fading grid currently shows hardcoded placeholder names. Eventually it should dynamically pull a randomized subset of real donor names from the /donor-wall/ page's ACF repeater data, so names only need to be maintained in one place.
PHP logic (for the Give Back template or a shortcode):
// 1. Get the Donor Wall page
$wall_page = get_page_by_path('donor-wall');

// 2. Collect all donor names from ACF repeater
$all_donors = [];
if( have_rows('facilities', $wall_page->ID) ):
  while( have_rows('facilities', $wall_page->ID) ): the_row();
    if( have_rows('donor_tiers') ):
      while( have_rows('donor_tiers') ): the_row();
        if( have_rows('donors') ):
          while( have_rows('donors') ): the_row();
            $all_donors[] = get_sub_field('donor_name');
          endwhile;
        endif;
      endwhile;
    endif;
  endwhile;
endif;

// 3. Shuffle and take 24 (8 per page x 3 pages)
shuffle($all_donors);
$display_donors = array_slice($all_donors, 0, 24);
Dependency: This change depends on the Donor Wall page and its ACF field group being set up first. Until then, the hardcoded names from the mockup can remain in place.
