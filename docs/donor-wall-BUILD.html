New Page
Page Overview
Build a new /donor-wall/ page as a custom page template. This page displays all donors organized by facility (Beis Kushner, Beren Arena, Mercazia PAC, Dining Hall). Each facility has a hero-style header, a primary dedication plaque, sub-dedications grid, and tiered donor name lists.
Unique design elements: Uses a gold accent color (#B8953E) for labels and eyebrows. Facilities alternate between white and warm grey (#F8F7F5) backgrounds. A sticky facility nav sits below the hero.
Sections:
1. Hero (centered, gold accents)
2. Sticky facility navigation bar
3. Facility sections (repeating pattern per facility):
   a. Facility header (eyebrow + name + description)
   b. Primary dedication plaque (dark green, centered)
   c. Sub-dedications grid (cards with green left border)
   d. Donor tiers (Benefactors, Patrons, etc. with name columns)
4. Closing CTA section
Mockup: morasha-donor-wall.html
Color palette note: The donor wall uses the standard green palette but adds:
--gold: #B8953E (labels on dark backgrounds)
--gold-light: #F5EFDF
--bg-warm: #F8F7F5 (alternating facility backgrounds)

Cross-Page Connection
Give Back Page: Fading Grid Connection
The fading donor grid on the /give-back/ page should dynamically pull names from this Donor Wall's ACF data. This means donor names only need to be entered once (on this Donor Wall page), and the Give Back page reads from the same source.
How it works:
// In the Give Back template or shortcode:
$wall_page = get_page_by_path('donor-wall');
$all_donors = [];

if( have_rows('facilities', $wall_page->ID) ):
  while( have_rows('facilities', $wall_page->ID) ): the_row();
    if( have_rows('donor_tiers') ):
      while( have_rows('donor_tiers') ): the_row();
        if( have_rows('donors') ):
          while( have_rows('donors') ): the_row();
            $all_donors[] = get_sub_field('donor_name');
          endwhile;
        endif;
      endwhile;
    endif;
  endwhile;
endif;

// Shuffle and take 24 (8 per page x 3 pages)
shuffle($all_donors);
$display_donors = array_slice($all_donors, 0, 24);
Key point: The Donor Wall ACF fields must be set up and populated BEFORE the Give Back fading grid can work with real names. Build the Donor Wall page first, populate data, then connect the Give Back page.
