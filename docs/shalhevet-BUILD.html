New Page
Page Overview
Build a new /shalhevet/ page for the Shalhevet Newsletter archive. This page uses the standard Morasha green palette. It has three main areas: a hero, a featured issues grid (current summer), and a full archive organized by decade with pill-style navigation.
Sections:
1. Hero with subtle radial gradients
2. Featured Issues grid (current summer's issues)
3. Full Archive with decade pill navigation + year-organized rows
Mockup: morasha-shalhevet.html
Scope of the archive: The mockup includes issues going back to 1974. That is a LOT of data. The ACF structure needs to handle decades of content efficiently.
WordPress Implementation
Page Template: page-shalhevet.php
Template Name: Shalhevet Newsletter
Stylesheet: shalhevet.css — enqueue conditionally
ACF Field Group: "Shalhevet Newsletter"
Group: Featured Section
  ├── featured_eyebrow    // Text — "Summer 2025"
  ├── featured_heading    // Text — "The latest issues"
  └── Repeater: featured_issues
        ├── issue_label     // Text — "Issue 1"
        └── issue_pdf       // File (PDF) — the PDF link

Repeater: decades
  ├── decade_label        // Text — "The 2020s"
  ├── decade_anchor       // Text — "decade-2020" (for pill nav)
  └── Repeater: years
        ├── year            // Text — "2025"
        └── Repeater: issues
              ├── issue_label // Text — "Issue 1"
              └── issue_url   // URL — direct PDF link
Alternative approach: Given the volume of data (50+ years), Izzy may want to consider a simpler approach: store the archive as a single WYSIWYG or code field per decade, rather than deeply nested repeaters. This avoids ACF performance issues with 3-level nested repeaters containing hundreds of rows. Discuss with David which approach is more maintainable.

Data Entry Notes
The archive spans 6 decades (2020s through 1970s) with a total of approximately 50 years of issues. All PDF URLs are already established on the existing campmorasha.com domain (paths like /wp-content/uploads/YEAR/MONTH/filename.pdf).
Important for Izzy: All issue links should open in a new tab (target="_blank" rel="noopener"). The featured issues section duplicates links from the archive's most recent year — this is intentional so the current summer stands out at the top.
Performance consideration: With ~300 individual issue links on the page, keep the DOM simple. The mockup uses plain <a> tags inside flex containers — no cards or complex markup needed for the archive rows.
