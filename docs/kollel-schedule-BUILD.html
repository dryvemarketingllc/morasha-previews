New Page
Page Overview
Build a new /kollel/schedule/ page for the Morasha Kollel daily schedule. This page uses the Kollel terracotta color palette (not the standard green). It displays two schedule tracks side-by-side: High School Kollel and 12th Grade Kollel.
Sections:
1. Hero with terracotta radial gradients
2. Two-column schedule grid with time/activity rows
Mockup: morasha-kollel-schedule.html
Kollel Color Palette (overrides the site-wide green):
--green: #974426 (terracotta primary)
--dark-green: #5e2511 (terracotta dark)
--darkest-green: #3d1808 (deep brown, hero/headings)
--light-green: #c79685 (terracotta light)
--lightest-green: #e9cec5 (terracotta accent bg)
WordPress Implementation
Page Template: page-kollel-schedule.php
Template Name: Kollel Schedule
Stylesheet: kollel-schedule.css — enqueue conditionally
ACF Field Group: "Kollel Schedule"
Repeater: tracks
  ├── track_eyebrow      // Text — "Track 1"
  ├── track_name         // Text — "High School Kollel"
  └── Repeater: schedule_rows
        ├── time           // Text — "7:45 AM"
        ├── activity       // Text — "Shacharis"
        └── activity_note  // Textarea — optional detail text
PHP loop structure:
<?php /* Template Name: Kollel Schedule */
get_header();
?>
<section class="hero">...</section>
<section class="schedules">
  <div class="schedules-inner">
    <div class="grid">
<?php
if( have_rows('tracks') ):
  while( have_rows('tracks') ): the_row(); ?>
    <div class="track">
      <div class="track-head">
        <div class="eyebrow"><?php the_sub_field('track_eyebrow'); ?></div>
        <h3><?php the_sub_field('track_name'); ?></h3>
      </div>
      <?php if( have_rows('schedule_rows') ):
        while( have_rows('schedule_rows') ): the_row(); ?>
        <div class="row">
          <div class="time"><?php the_sub_field('time'); ?></div>
          <div class="activity">
            <div class="activity-label"><?php the_sub_field('activity'); ?></div>
            <?php if( get_sub_field('activity_note') ): ?>
              <div class="activity-note"><?php the_sub_field('activity_note'); ?></div>
            <?php endif; ?>
          </div>
        </div>
      <?php endwhile; endif; ?>
    </div>
  <?php endwhile; endif; ?>
    </div>
  </div>
</section>
<?php get_footer(); ?>

  • Hero uses deep brown (#3d1808) with terracotta radial gradients
  • Two schedule tracks display side-by-side on desktop

  • Time text is Roboto Condensed, bold, uppercase, terracotta color
  • Activity labels are serif font, 17px, deep brown
  • Activity notes (where present) appear below the label in grey
  • Row dividers are subtle 1px lines at 10% opacity
  • At 1024px breakpoint, tracks stack vertically
  • At 640px, time column shrinks to 100px and font sizes reduce
  • All schedule data is editable via ACF repeater
  • Page uses site-wide nav and footer
