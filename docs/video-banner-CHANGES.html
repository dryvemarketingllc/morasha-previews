2. Video player — poster overlay pattern

Don't load a YouTube iframe on page load. Instead, show a thumbnail image with a custom play button. Clicking it loads the embed with autoplay. This gives zero YouTube branding before play.
How it works
  • Poster overlay sits on top of a hidden iframe (z-index: 2)
  • Background-image from YouTube: https://img.youtube.com/vi/{ID}/maxresdefault.jpg
  • Custom play button: 64px white circle, green triangle (#46764B)
  • Video title overlay at bottom-left over a dark gradient
  • On click: set iframe src to embed URL with autoplay, fade out poster
YouTube embed parameters
?modestbranding=1&rel=0&iv_load_policy=3&color=white&autoplay=1

3. Dot navigation + auto-slide

Dots below the video let users switch between videos. Auto-slide cycles every 5 seconds and pauses when a video is playing.
Behavior
  • Dots are generated by JS from the video array
  • Active dot: white, scaled 1.2x. Inactive: rgba(255,255,255,0.3)
  • Auto-slide every 5 seconds — cycles to next poster
  • Stops auto-slide when a video is playing (iframe loaded)
  • Clicking a dot while video is playing: stops video, shows new poster, resumes auto-slide
CSS — Dots
.video-dots {
  display: flex; gap: 10px;
  margin-top: 16px;
  justify-content: center;
}

.dot {
  width: 10px; height: 10px;
  border-radius: 50%;
  background: rgba(255,255,255,0.3);
  cursor: pointer;
  transition: all 0.25s;
  border: none; padding: 0;
}
.dot.active { background: #fff; transform: scale(1.2); }
JavaScript
// Video data — pull from ACF repeater
var videos = [
  { id: '6o8Iof5L5Fw', title: 'Summer 2025 Trailer' },
  { id: 'dK3deR3XYOQ', title: 'Sulam Promo' },
  // ... more from ACF
];

// Auto-slide — stops when video is playing
function startAutoSlide() {
  stopAutoSlide();
  autoSlideTimer = setInterval(function() {
    if (!isPlaying) {
      goToVideo((currentIndex + 1) % videos.length);
    }
  }, 5000);
}

// Set poster — show thumbnail, hide iframe
function setPoster(index) {
  poster.style.backgroundImage =
    'url(https://img.youtube.com/vi/' + videos[index].id + '/maxresdefault.jpg)';
  poster.classList.remove('hidden');
  iframe.src = '';
  isPlaying = false;
}

// Play — load iframe, hide poster
function playVideo() {
  iframe.src = 'https://www.youtube.com/embed/' + videos[currentIndex].id + embedParams;
  poster.classList.add('hidden');
  isPlaying = true;
  stopAutoSlide();
}

6. ACF fields needed

Create these ACF fields on the homepage (or options page) so content is editable without code changes.
Section settings
  • season_label — Text — e.g. "Summer 2026"
  • date_range — Text — e.g. "June 30 – August 18"
  • grade_range — Text — e.g. "3rd – 9th Grade Boys & Girls"
Video repeater
  • video_youtube_id — Text — Just the ID, not the full URL (e.g. 6o8Iof5L5Fw)
  • video_title — Text — Shows on poster overlay bottom-left
Quick links repeater
  • link_label — Text — Button text (e.g. "Dates & Rates")
  • link_url — URL — Destination page
  • link_icon — Select — Dropdown: calendar, pencil, star, mail, map-pin, users, camera, book, heart, clipboard, info
Store the SVG paths in a PHP helper function that outputs the correct icon based on the select value. The full set of SVG paths is in the preview HTML source.
