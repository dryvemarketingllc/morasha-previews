How It Works

Each card has two stacked background layers (.bg and .bg-alt). A simple JS timer crossfades between them every 4 seconds using CSS opacity transitions (1.2s ease). Hovering any card pauses its timer so the current photo stays visible.

Implementation for WordPress

  • Add a second <div class="bg-alt"> inside each .camp-card, right after the existing .bg div
  • Set the alternate photo as an inline background-image on .bg-alt
  • Add the small dot indicators (<div class="dots">) — optional but helps signal that images cycle
  • The JS below handles the crossfade timer and hover pause
  • Each card's timer is offset by 1 second so all 4 don't switch in unison

Photo Pairing Notes

For the actual implementation, pair each camp with one photo of each gender (or a coed group shot as the alternate). Current placeholder pairings use campus photos from the staging site's uploads folder — swap these with the real gendered pairs once selected.
