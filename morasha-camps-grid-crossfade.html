Camp Cards — Crossfade Implementation

Changes to the homepage .morasha-camps__grid section. No changes to existing card layout or styling.

1. Overview

Each .camp-card gets a second background image that crossfades on a 4-second timer. The existing card structure, styles, aspect ratio, color bars, and tint hover behavior are all preserved — this adds two new elements and a small script.

2. HTML Changes

Inside each .camp-card, add two elements after the existing .bg div:

<!-- Existing card structure -->
<a class="camp-card" data-camp="morasha" href="/about">
  <div class="bg" style="background-image:url('photo-1.jpg')"></div>

  <!-- ✦ NEW: alternate background image -->
  <div class="bg-alt" style="background-image:url('photo-2.jpg')"></div>

  <div class="tint"></div>
  <div class="content">
    <h3>Camp<br>Morasha</h3>
  </div>

  <!-- ✦ NEW: dot indicators (optional) -->
  <div class="dots"><span class="active"></span><span></span></div>
</a>
If a card has only one photo (no alternate needed), simply omit .bg-alt and .dots. The JS skips cards without a .bg-alt.

3. CSS to Add

Append these rules to the existing camp card stylesheet. No changes to existing rules needed.

/* ── Crossfade: alternate background layer ── */
.camp-card .bg-alt {
  position: absolute;
  inset: 0;
  background-size: cover;
  background-position: center;
  opacity: 0;
  transition: transform 1s cubic-bezier(0.2, 0.8, 0.2, 1),
              opacity 1.2s ease-in-out;
  z-index: 1;
}
.camp-card .bg-alt.active { opacity: 1; }
.camp-card .bg.hidden     { opacity: 0; }

/* Hover zoom applies to both layers */
.camp-card:hover .bg-alt {
  transform: scale(1.06);
}

/* ── Dot indicators ── */
.camp-card .dots {
  position: absolute;
  bottom: 20px;
  right: 16px;
  z-index: 5;
  display: flex;
  gap: 6px;
}
.camp-card .dots span {
  width: 6px;
  height: 6px;
  border-radius: 50%;
  background: rgba(255,255,255,0.4);
  transition: background 0.4s, transform 0.3s;
}
.camp-card .dots span.active {
  background: #fff;
  transform: scale(1.3);
}

4. JavaScript

Add to the homepage JS (or as an inline script after the camps grid). No dependencies.

/* Camp card crossfade — 4s interval, 1s stagger, hover pauses */
(function() {
  var cards = document.querySelectorAll('.camp-card');

  cards.forEach(function(card, index) {
    var bg    = card.querySelector('.bg');
    var bgAlt = card.querySelector('.bg-alt');
    var dots  = card.querySelectorAll('.dots span');
    if (!bg || !bgAlt) return; // skip cards without alt image

    var showingAlt = false;
    var paused = false;

    function toggle() {
      if (paused) return;
      showingAlt = !showingAlt;
      bg.classList.toggle('hidden', showingAlt);
      bgAlt.classList.toggle('active', showingAlt);
      if (dots.length === 2) {
        dots[0].classList.toggle('active', !showingAlt);
        dots[1].classList.toggle('active', showingAlt);
      }
    }

    // Stagger each card by 1s so they don't all flip together
    setTimeout(function() {
      setInterval(toggle, 4000);
    }, index * 1000);

    // Pause on hover
    card.addEventListener('mouseenter', function() { paused = true; });
    card.addEventListener('mouseleave', function() { paused = false; });
  });
})();

5. Behavior Summary

BehaviorDetail
Crossfade interval4 seconds per image
Transition duration1.2s ease-in-out opacity
Stagger offset1 second between each card (card 1 starts at 0s, card 2 at 1s, etc.)
HoverPauses crossfade timer; existing zoom + tint hover effects still work on both layers
Mobile / touchCrossfade runs continuously (no hover pause on touch). No additional touch handling needed.
FallbackIf .bg-alt is missing, card displays single image as before — fully backward compatible
Dot indicatorsOptional. 6px white dots, bottom-right corner, above color bar. Active dot scales to 1.3×

6. WordPress Custom Field (Suggested)

Add an ACF or custom meta field called camp_card_alt_image (image type) to the homepage camps block. In the template, output the second .bg-alt div only when this field has a value. This lets editors swap alternate photos without code changes.

7. Photo Pairing Notes

The current mockup uses placeholder campus photos from /wp-content/uploads/2026/05/. For production, pair each coed camp with one photo showing boys and one showing girls (or a mixed group shot). Non-coed camps can omit .bg-alt entirely.
