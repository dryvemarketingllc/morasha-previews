Global Font Swap: Kefa + Nunito Sans Fallback
Replace the sans-serif font stack across the site. Kefa (Apple system font) becomes the primary, with Nunito Sans as a Google Fonts fallback for Windows/Android. Keep Roboto on text under 14px for legibility. Georgia stays on serif headings — no change there.
Step 1: Add Nunito Sans to the theme's <head>:
<link href="https://fonts.googleapis.com/css2?family=Nunito+Sans:wght@400;500;600;700&display=swap" rel="stylesheet">
Step 2: Add a CSS custom property in :root:
:root {
  --font-primary: Kefa, 'Nunito Sans', sans-serif;
}
Step 3: In style.css, find-and-replace every font-family declaration that references Roboto, Montserrat, or Nohemi with var(--font-primary).
Step 4: Add an exception for small text:
/* Keep small UI text on Roboto for crispness */
.site-footer a,
.sub-menu a,
.form-label,
small,
figcaption {
  font-family: 'Roboto', sans-serif;
}
Why Kefa? It matches the brand's print materials (invitations, flyers) and has a warm, organic feel that fits Morasha better than Roboto. Since it's a system font on Apple devices, there's zero load-time cost for most of the audience. Nunito Sans provides a visually similar experience on non-Apple platforms.
Scope: Global — all pages. Georgia serif headings are not affected.
Files: style.css, theme header.php (for the Google Fonts link)

Give Back Page: Donor Block Should Pull Real Names
The fading grid donor block on /give-back/ currently shows placeholder names. It should dynamically pull a subset of real donor names from the same ACF data that powers the full /donor-wall/ page, so names only need to be maintained in one place.
How it works:
// In the Give Back template (or a shortcode/block):
// 1. Get the Donor Wall page by slug or ID
$wall_page = get_page_by_path('donor-wall');

// 2. Pull all donor names from the ACF repeater
$all_donors = [];
if( have_rows('facilities', $wall_page->ID) ):
  while( have_rows('facilities', $wall_page->ID) ): the_row();
    if( have_rows('donor_tiers') ):
      while( have_rows('donor_tiers') ): the_row();
        if( have_rows('donors') ):
          while( have_rows('donors') ): the_row();
            $all_donors[] = get_sub_field('donor_name');
          endwhile;
        endif;
      endwhile;
    endif;
  endwhile;
endif;

// 3. Shuffle and take 24 names (8 per page × 3 pages)
shuffle($all_donors);
$display_donors = array_slice($all_donors, 0, 24);
Key point: Donor names are entered once on the Donor Wall page via ACF. The Give Back fading grid reads from that same data — no duplicate entry needed. When a new donor is added to the wall, they automatically appear in the Give Back rotation.
Previews: Give Back with donor block  |  Full Donor Wall
Scope: /give-back/ page template. Depends on the Donor Wall ACF fields (Change #4) being set up first.
