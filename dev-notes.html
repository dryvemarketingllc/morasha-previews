Global Font Swap: Kefa + Nunito Sans Fallback
Replace the sans-serif font stack across the site. Kefa (Apple system font) becomes the primary, with Nunito Sans as a Google Fonts fallback for Windows/Android. Keep Roboto on text under 14px for legibility. Georgia stays on serif headings — no change there.
Step 1: Add Nunito Sans to the theme's <head>:
<link href="https://fonts.googleapis.com/css2?family=Nunito+Sans:wght@400;500;600;700&display=swap" rel="stylesheet">
Step 2: Add a CSS custom property in :root:
:root {
  --font-primary: Kefa, 'Nunito Sans', sans-serif;
}
Step 3: In style.css, find-and-replace every font-family declaration that references Roboto, Montserrat, or Nohemi with var(--font-primary).
Step 4: Add an exception for small text:
/* Keep small UI text on Roboto for crispness */
.site-footer a,
.sub-menu a,
.form-label,
small,
figcaption {
  font-family: 'Roboto', sans-serif;
}
Why Kefa? It matches the brand's print materials (invitations, flyers) and has a warm, organic feel that fits Morasha better than Roboto. Since it's a system font on Apple devices, there's zero load-time cost for most of the audience. Nunito Sans provides a visually similar experience on non-Apple platforms.
Scope: Global — all pages. Georgia serif headings are not affected.
Files: style.css, theme header.php (for the Google Fonts link)

Navigation: Color-Coded Dropdown Borders
Add colored left borders to dropdown menu items based on which camp section they belong to. This helps users visually distinguish between Camp Morasha, Kehilas Yaakov, Kollel, and Travel. 
/* Camp-specific accent colors */
#menu-item-6044 a { border-left: 3px solid #46764B; } /* Camp Morasha — green */
#menu-item-6045 a { border-left: 3px solid #1C326B; } /* Kehilas Yaakov — indigo */
#menu-item-6046 a { border-left: 3px solid #974426; } /* Kollel — sienna */
#menu-item-6047 a { border-left: 3px solid #306DA5; } /* Travel — blue */

.sub-menu a:hover {
  background: #f7f9f4;
  padding-left: 12px;
}
Note: These target WordPress menu item IDs. If menu items are re-created, the IDs will change and these selectors will need updating. A more robust approach would use a custom CSS class added via nav_menu_css_class filter.
Scope: Global — main navigation on all pages.
Files: style.css
