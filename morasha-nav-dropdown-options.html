Nav dropdowns — interactive options

Four paired takes on the About and Programs dropdowns using the real MorashaCamps.com nav. Now actually interactive — hover the nav items to open the dropdowns.

Try it: Hover About or Programs in each nav bar. On Option 1, hovering Morasha Travel reveals its cascade panel. On Option 3, hovering items swaps the preview pane photo.
Option 1

Classic paired dropdowns

Both dropdowns use the same slim vertical-list pattern. Programs gets a brand-color left bar per camp, and Morasha Travel opens a side-cascade panel with Sulam / Amcha Boys / Amcha Girls.
